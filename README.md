# 🤖 大模型工程实践（LLM Agent Engineering）· 从入门到精通

> 📘 28章 实战体系 · 交互式 HTML 课程

> **English TL;DR:** An all-Chinese 28-chapter, framework-agnostic-to-framework course on **LLM Agent engineering** — founder-level loop (perceive-think-act / ReAct, prompt & CoT, Function Calling), memory systems, multi-agent collaboration & orchestrations, then a practical tour of the ecosystem in 2026: LangChain 1.x / LangGraph (state graphs, checkpoints, conditional loops), RAG agents, AutoGen / GroupChat / MAF, OpenManus, CrewAI (roles/tasks/crews), MCP & A2A, and vendor SDKs (OpenAI Agents / Google ADK / Claude Agent SDK). Production tail: observability/LangSmith, testing with mock LLMs, cost/performance, security & compliance (prompt injection, PII), ending with two capstones (intelligent customer service; automated research assistant) and a framework-selection decision tree.

## 📖 课程简介

本课程面向想系统掌握 **LLM Agent 工程**的开发者：从 Agent 基础概念、感知-思考-行动循环（ReAct）与工具调用讲起，建立通用的记忆、多 Agent 协作与中间件心智模型；随后用大量章节实战走遍 2026 主流框架——LangChain 1.x / LangGraph、RAG Agent、AutoGen & GroupChat、OpenManus、CrewAI、MCP/A2A 与厂商原生 SDK——再覆盖生产化：可观测监控、测试与质量、成本优化、安全合规，最后以智能客服与自动化研究助手两个完整项目收束，并给出框架选型决策树。
